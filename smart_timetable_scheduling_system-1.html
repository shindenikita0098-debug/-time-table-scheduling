Recommended workflow

  1. Add teachers with unique teacher IDs.
  2. Add subjects and assign a teacher to each subject.
  3. Add classes and divisions, for example SYBSC IT — A.
  4. Add rooms and daily lecture time slots.
  5. Generate the timetable and review any unassigned subjects.
  6. Open View Timetable and press Print / Save as PDF.

Data is saved in this browser on this device using local storage. It will not automatically appear on another phone or computer.
